== Description ==

By stopping WooCommerce from sending data to its tracking endpoint, 
this lightweight WordPress plugin WooCommerce Telemetry Blocker for WooCommerce improves the privacy and respcect DNT, GDPR of your website. 
The WooCommerce tracker's telemetry is blocked and the tracking data is deleted upon activation.


== Installation ==

1. Upload 'woocommerce-telemetry-blocker.zip' to the '/wp-content/plugins/' directory
2. Extract the Plugin to a `woocommerce-telemetry-blocker` Folder
3. Activate the plugin through the 'Plugins' menu in WordPress


1. Go to `Plugins` in the Admin menu
2. Click on the button `Add new`
3. Search for 'woocommerce-telemetry-blocker` and click 'Install Now' or click on the `upload` link to upload `woocommerce-telemetry-blocker.zip`
4. Click on `Activate plugin`
